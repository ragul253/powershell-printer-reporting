# Printer Counter and Device Status Reporting

**Professional project overview**

> Repository status: project overview published. Original source files, configurations and supporting documentation will be added later. No runnable implementation is included yet.

## Overview

Used PowerShell and read-only SNMP to collect printer usage counters and device status, export CSV reports and record offline or DNS-unresolved devices for follow-up. Reconciled remote data with on-site checks and manual readings when printers were inaccessible or absent from print-server inventory.
